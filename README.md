# Cycling Career — V1

Simulation de carrière cycliste jouable dans le navigateur. Cette V1 contient la création du coureur, l'entraînement, l'avancement du temps, six courses fictives, des décisions tactiques, la progression et une sauvegarde locale versionnée.

## Commandes

```bash
pnpm install
pnpm dev
pnpm test
pnpm build
```

Le moteur (`src/game`) ne dépend pas de React. Les données fictives sont isolées dans `src/data` pour pouvoir être remplacées ultérieurement.
